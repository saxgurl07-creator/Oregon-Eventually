# Oregon, Eventually

**A JavaScript Road Trip Adventure**

*Learn to code. Try not to die.*

An original Commodore-era inspired Oregon Trail coding adventure. Learn JavaScript through eight interactive chapters, with a no-game-over recovery mechanic.

## Run locally

Install Node.js, then run `npm install` and `npm run dev`.

## Publish

This project includes a GitHub Pages workflow. In repository Settings → Pages, choose **GitHub Actions** as the source. Once the deployment succeeds, play at the GitHub Pages URL for the repository (after renaming: https://saxgurl07-creator.github.io/oregon-eventually/).

## Notes

The challenge checker recognizes specific expected syntax; it does not execute arbitrary user code. Progress is stored locally in your browser. Visuals are original retro-inspired CSS art.
